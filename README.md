One sentence, 222 characters, written to convince a friend who has never coded to let an AI agent build their first app idea on make.fun. The program in `main.ts` writes that single sentence to `/output/entry.txt` — no input, no randomness — and the sentence itself is the whole entry: warm, plain-spoken, and careful to promise only a real first version the friend can tap through, never overnight success.

## Run it

```sh
node main.ts
```
